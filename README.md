# 2nd React App

## Description

This is a test project created using React. The purpose of this project is to practice React basics and demonstrate small features or concepts.

## Purpose

- Learning: To improve my understanding of React fundamentals.
- Feedback: Share this project with instructors or peers to get constructive feedback.
- Teaching: Use this as a reference for explaining concepts to others in the future.

### How to Run

Clone the repository :

```bash
git clone https://github.com/Tester1321/2nd-React.git
```

Install dependencies :

```bash
npm install
```

Start the development server :

```bash
npm run dev
```

## Features

- A basic React structure using functional components.
- Styled using basic CSS.
